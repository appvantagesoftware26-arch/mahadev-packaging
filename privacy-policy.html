This is a global policy intended to apply to multiple applications, client applications, administrative applications, shopping applications, and future applications operated using the AppVantage Software platform.

Important: Different applications and clients may use different features. Therefore, an individual application may not collect or access every category of information described in this Privacy Policy. 1. About AppVantage Software

AppVantage Software is an independent software developer and application administrator based in India.

AppVantage Software develops and manages applications for multiple businesses and clients. Examples of applications currently or previously developed or managed through the platform may include applications for Mahadev Packaging, JBF, Market Point, SFS, and other client businesses.

Application names, branding, icons, features, and functionality may differ between clients.

2. Multi-Client Platform

AppVantage Software may operate a shared technical infrastructure for multiple client applications.

This infrastructure may include a shared backend and database. Client and application data is logically separated using client-specific identifiers and access controls.

A user's information is intended to be associated with the relevant client, application, or business account and is not intended to be made available to unrelated clients.

Data separation: Multiple client applications may use the same technical infrastructure, but client data is logically separated. A client application is intended to access only the data associated with its authorized client/business environment.
